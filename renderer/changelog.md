# GoonCall Changelog

## v1.2.0 — The Two-Person Empire
- **Whiteboard** in calls — draw together on a shared canvas (pen cycles colors)
- **Watch queue** — line up videos, they autoplay next
- **Playback speed sync** — 1x / 1.25 / 1.5 / 2x, synced both sides
- **Quick screenshot** — Snip button grabs your screen and sends it instantly
- **Pinned messages** — right-click Pin, chips above chat jump back
- **Nudge** — shake their app when they're ignoring you
- **Quote-jump** — click any reply quote to fly to the original message
- **Sound packs** — Send pack / Import pack shares your whole board as one file
- **Stop all sounds** button
- **Custom ringtones** — pick any soundboard clip as someone's ringtone
- **Free TURN relay added** — better call success on strict networks
- Discord-style UI overhaul: icon rail, DM list, flat messages, floating call dock, Ctrl+K switcher

## v1.1.10 — The Big Look

- Filter box for acquaintances
- Avatars are color-matched between you and your friend automatically
